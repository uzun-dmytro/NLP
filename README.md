# Базові алгоритми обробки природної мови

Навчальний репозиторій для дисципліни **"Базові алгоритми обробки природної мови"**.

Тут будуть зберігатися мої практичні роботи, домашні завдання, експерименти з текстовими даними та, можливо, фінальний проєкт з NLP.

## Що буде в репозиторії

- скрипти для попередньої обробки текстів;
- домашні та практичні завдання з дисципліни;
- експерименти з алгоритмами обробки природної мови;
- допоміжні файли для роботи з текстовими корпусами;
- матеріали фінального проєкту, якщо він буде виконуватися в межах цього репозиторію.

## Поточний вміст

- `docx_to_txt.py` - скрипт для конвертації `.docx` файлу в `.txt`;
- `Uzun_file_1.txt` - текстовий файл, який використовується для подальшої обробки;
- `create_file_2_json.py` - заготовка для наступного етапу роботи з даними.

## Дані

У репозиторії можуть з'являтися великі текстові файли, потрібні для лабораторних або домашніх робіт. Бінарні документи, тимчасові файли, віртуальні середовища та IDE-налаштування не додаються в Git.

Якщо текстові дані будуть занадто великими або не призначеними для публічного поширення, вони зберігатимуться локально, а в репозиторії залишатимуться тільки код та інструкції для відтворення роботи.

## Технології

Основна мова роботи - **Python**.

Залежності та структура проєкту можуть змінюватися протягом курсу залежно від завдань.
